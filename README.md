# html-to-shopify — ARCHIVADO

Este repo era el esqueleto v0.1 del método HTML → Shopify. **El método vive ahora en el plugin
`metodo-web` como la skill `html-shopify`** (v1.0, validada en un proyecto real):

- repo: [`alvarog6/smart-sites-metodo`](https://github.com/alvarog6/smart-sites-metodo) →
  `metodo-web/skills/html-shopify/`
- instalar: `claude plugin marketplace add alvarog6/smart-sites-metodo` y
  `claude plugin install metodo-web@smart-sites`; la skill aparece como `metodo-web:html-shopify`.

No se mantiene. No clonarlo en `~/.claude/skills`: duplicaría la skill del plugin.
